# whidev

Personal website and portfolio of [Minas Giannekas](https://whidev.com) — self-employed web and app developer from Greece.

Live at **[whidev.com](https://whidev.com)**.

## About

A static single-page site showcasing personal projects, skills, freelance work, and contact info. Featured projects include [MapChart](https://www.mapchart.net), [MapGame](https://mapgame.net), [Shortcut Keeper](https://shortcutkeeper.com), [TennisSwipeTrivia](https://tennisswipe.app), and [CreateFormation](https://createformation.com).

## Tech

- HTML, CSS ([Skeleton](https://getskeleton.com/) grid)
- Optional [Gulp](https://gulpjs.com/) pipeline for concatenating and minifying CSS into `dist/css/`
